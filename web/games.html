Umbra Engine · 100-game program

UMBRA ARCADE

Every game ships to the AAA-feel bar: particles, screen shake, hit-stop, floating text, and procedurally synthesized sound — plus a full LLM action surface for agents to play them. Click PLAY to launch a game in your browser (WASM).

PROGRESS

Play links expect the WASM builds in web/ (games land in web/games/<name>/index.html). Build everything with ./build_wasm.sh or make wasm, then serve the folder:

cd web && python3 -m http.server 8000 → http://localhost:8000/games.html

Every shipped game also exposes getState() + named actions (e.g. move_left, place, restart) so LLM agents can play the exact same build. Pause with P, restart with R.
